# 분석 계획

본 문서는 어떤 통계 방법으로 무엇을 판정할지를 실험 착수 이전에 고정한다.

---

## 1. 비교 설계

S4와 S5는 동일한 질의 집합에서 실행되므로 **대응 표본**으로 처리한다. 독립 표본 검정을 사용하지 않는다.

| 지표 유형 | 검정 |
|---|---|
| 이진 결과(위반쌍 여부) | McNemar 검정 |
| 연속형 지표(DL_A^M, nDCG@5, 지연) | Wilcoxon 부호순위 검정 |
| 비율의 신뢰구간 | Wilson 95% 구간 |
| 평균의 신뢰구간 | 부트스트랩 2,000회 재표본, 95% |

정규성을 가정하지 않는 검정을 선택한 이유는 지연 분포의 우측 꼬리와 질의별 품질 편차 때문이다.

**유의수준 α = 0.05.** 다섯 변형축과 다수 가설에 대해 복수 검정을 수행하므로 **Holm-Bonferroni** 절차로 보정한다.

---

## 2. 무사건 관측의 처리

DL_A@k나 TCV@k가 0으로 관측되면 부트스트랩 신뢰구간이 [0, 0]으로 축약되어 정보를 제공하지 못한다. 이 경우 **Rule of Three**를 적용하여 95% 신뢰상한을 3/n으로 보고한다.

```
p̂_upper(95%) = 3 / n
```

여기서 n은 제외 규칙을 통과한 유효 대조쌍 수이다. 판정기준 0.0075를 만족하려면 **n ≥ 400**이어야 하므로, 대조 질의 생성 단계에서 이 조건을 먼저 확인한다.

무사건 관측의 해석은 다음 문장으로 고정한다.

> 위반이 관측되지 않았다는 사실은 위반 확률이 0임을 의미하지 않으며, 시험한 대조쌍의 범위에서 위반이 발견되지 않았고 그 95% 상한이 위 값이라는 의미이다.

---

## 3. 효과크기

유의성만으로 결론을 내리지 않으며 효과크기를 병기한다.

| 지표 유형 | 효과크기 | 해석 구간 |
|---|---|---|
| 이진 | 위험차와 95% 신뢰구간 | — |
| 연속 | Cliff's delta | \|δ\| < 0.147 negligible, < 0.33 small, < 0.474 medium, 이상 large |

**표본이 클 때의 처리.** 유효 대조쌍이 1,000개를 넘는 조건에서는 실무적으로 무의미한 차이도 통계적으로 유의할 수 있다. 따라서 효과크기가 사전에 정한 실무 임계값에 미달하면 **유의하더라도 개선으로 보고하지 않는다.**

---

## 4. 천장·바닥 효과의 처리

중간 후보 위반쌍 비율은 조건에 따라 0 또는 1에 근접할 수 있다. 두 시스템의 비율이 각각 양 끝에 붙으면 McNemar 검정은 불일치 쌍이 전부 한 방향이 되어 **p값이 효과의 크기가 아니라 표본 크기의 함수**가 된다.

이 경우 다음을 따른다.

1. 위반쌍 비율은 기술 통계로만 보고한다.
2. 결론은 평균값의 Wilcoxon 검정과 Cliff's delta, 그리고 신뢰구간으로 진술한다.
3. p값을 근거로 우열을 주장하지 않는다.

## 5. 지표별 산출식

| 지표 | 산출 |
|---|---|
| DL_A | \|(E(q′) ∖ E(q)) ∩ Ā(u,t)\| |
| DL_A@k | 대조쌍 단위 평균. 위반쌍 비율을 병기 |
| DL_A^M | \|(M(q′,m) ∖ M(q,m)) ∩ Ā(u,t)\| |
| DL_A^M/m | 실측 \|M(q,m)\|의 평균으로 나눈 정규화값 |
| TCV@k | E(q′,u,t′,k) ⊄ A(u,t′)인 질의의 비율 |
| OBR | \|{c ∈ R(q) ∩ A₀(u,t) : c ∉ A(u,t)}\| / \|R(q) ∩ A₀(u,t)\| |
| Availability@k | E ∩ R(q) ∩ A(u,t) ≠ ∅ 인 질의의 비율 |
| ΔOBR_rel | (OBR_base − OBR_mitigated) / OBR_base |

정규화값의 분모는 명목 m이 아니라 **실측 \|M(q,m)\|** 를 사용한다. 인가 청크 수가 m에 미치지 못하는 조합에서 \|M\| < m이 되기 때문이다.

---

## 6. 효용 동등 제약

보안 지표만으로 배치를 비교하면 반환량을 줄여 지표를 개선하는 퇴화가 가능하다. 극단적으로 아무것도 반환하지 않는 시스템은 모든 보안 지표를 만족한다.

따라서 보안 비교는 다음이 성립할 때에만 유효한 것으로 간주한다.

```
nDCG@5(S_base) − nDCG@5(S_secure) ≤ δ    이고
Availability@5(S_secure) ≥ Availability@5(S_base)
```

**δ = 0.02.** 제약이 충족되지 않는 비교는 보안 개선이 아니라 반환량 감소로 해석하고 그렇게 보고한다.

## 7. 민감도 분석

결론이 특정 설정값에 의존하지 않음을 확인한다.

| 대상 | 조건 | 확인 사항 |
|---|---|---|
| 중간 후보 개수 | m ∈ {20, 50, 100} | DL_A^M/m의 안정성 |
| 반환 개수 | k ∈ {1, 3, 5, 10} | 배치 소요의 선형성 |

민감도 분석에서 결론이 뒤집히는 구간이 발견되면, 그 조건을 본문에 명시하고 결론의 적용 범위를 제한한다.

---

## 8. 라벨 신뢰도와 결론의 조건

민감도 격상의 정답 라벨은 과차단율에 직접 영향을 준다. 따라서 라벨 신뢰도를 결론의 조건으로 미리 규정한다.

| 항목 | 기준 | 미달 시 처리 |
|---|---|---|
| 자기 일치도(2주 간격 재라벨, 100개) | ≥ 0.90 | 판정 기준서 보완 후 전체 재라벨 |
| 제2 주석자 Cohen's κ(표본 10%) | ≥ 0.60 | **OBR 절대값 해석 유보.** 동일 라벨 위의 완화 기법 간 상대 비교는 유지 |

κ가 기준에 미달하는 경우, 그 사실을 결과 장과 논의 장에 명시하고 RQ2의 결론 범위를 제한한다.

---

## 9. 보고 형식

- 평균값은 소수점 넷째 자리까지, 비율도 넷째 자리까지 기재한다.
- p값이 0.001 미만이면 "< 0.001"로 표기한다.
- 값이 정확히 0이면 "0.0000"으로 기재하고 공란을 두지 않는다.
- 측정하지 않은 항목은 "미측정"으로 표기하며 0으로 대체하지 않는다.
- 모든 보안 지표는 가용성·품질 지표와 같은 표에 병기한다.
