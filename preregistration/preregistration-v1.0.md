**연구자** 이남구(Lee Nam Ku)
**대상** 실제 기관 규정 코퍼스를 사용하는 독립 재현실험
**등록 범위 제외** 학위논문(2026)의 본실험. 해당 실험은 이 등록 이전에 비식별 합성자료로 수행되었으며, 본 문서로 소급 사전등록의 지위를 주장하지 않는다.
**발행** 본 문서는 `preregistration-v1.0` Release로 확정하며, 확정 이후 재현실험을 개시한다.

## 1. 연구질문

**RQ1-a** 신원과 기준시점을 고정한 채 질의 표현만 변형했을 때, 검색 이전 게이트웨이의 노출집합은 허용 후보집합을 벗어나지 않는가. 사후 필터링 배치와 비교하여 차이가 관측되는가.

**RQ1-b** 질의의 기준시점이 변경되었을 때, 노출집합은 변경된 시점의 허용 후보집합과 정합하는가.

**RQ2** 내용 기반 민감도 격상이 유발하는 과차단은 어느 수준이며, 완화 기법을 적용했을 때 보안 조건과 검색 품질을 유지한 채 과차단을 감소시킬 수 있는가.

**RQ3** 대조 질의 기반 검증 절차와 게이트웨이 배치가 폐쇄망 운영 환경에서 수용 가능한 실행 비용 안에 있는가.

**RQ4** 정책 스냅샷의 암호학적 결속이 위변조와 재사용을 탐지하며, 그 검증 비용이 운영 가능한 범위인가.

## 2. 가설과 판정기준

| 가설 | 대응 RQ | 확인 대상 | 판정기준 |
|---|---|---|---|
| H1a | RQ1-a | 표현 변형에 대한 노출 불변성 | S5의 최종 DL_A@5 = 0 이고 중간 후보 DL_A^M@m = 0(전체 대조쌍 전수). 무사건 관측의 95% 신뢰상한(Rule of Three)이 0.0075 이하. 동시에 S4의 중간 후보 DL_A^M@m > 0인 쌍이 1개 이상 관측 |
| H1b | RQ1-b | 시점 변경 시의 정합성 | S5의 시점 정합성 위반율 TCV@5 = 0. 최신본 고정 기준선에서는 TCV@5 > 0 |
| H1c | RQ1-a | 인가 판단의 질의 독립성 | 정적 데이터플로우 분석에서 질의 텍스트가 인가 속성으로 유입되는 경로 0개. 역할 사칭 질의 100개에서 A(u,t) 해시 변화 0건 |
| H2a | RQ2 | 완화 기법의 효과 크기 | M1~M3 중 최소 1개가 격상 기준선 대비 OBR을 상대 30% 이상 감소 |
| H2b | RQ2 | 효과의 진위 | H2a 달성 조건에서 nDCG@5 하락 0.02 이하, Availability@5 감소 없음, DL_A@5 = 0 유지 |
| H3-a | RQ3 | 게이트웨이 오버헤드 | S5의 P95 지연이 접근통제 미적용 기준선 S3의 P95 대비 20% 이내 증가 |
| **H3-b** | RQ3 | 대조 검증 배치 비용 | **(1) 선형성: k ∈ {1,3,5,10}에 대한 배치 소요시간의 선형회귀 결정계수 R² ≥ 0.95 이고, k=10 소요가 k=1 소요의 8배 이상 12배 이하. (2) 총 소요: 전체 대조쌍 배치가 3,600초 이내 완료** |
| H3-c | RQ3 | 동시접속 처리 | 동시접속 10명 조건에서 P95 3초 이하 |
| H4a | RQ4 | 암호검증 탐지력 | 서명·스냅샷·허용집합 검증에서 정상 요청 전수 통과. 정의된 공격 유형 전수 탐지 |
| **H4b** | RQ4 | 암호검증 오버헤드 | **검증 절차 전체의 P95 지연이 50 ms 이하** |

### H3-b 기준값의 근거

대조 검증은 상시 서비스가 아니라 정책 변경이나 색인 재구축 시점에 수행하는 배치 절차이다. 따라서 단일 질의 대비 비율이 아니라 배치 전체의 완료 시간과 확장성으로 판정한다.

**선형성 조건**은 질의 하나당 원 질의 1회와 대조 질의 k회, 즉 (1 + k)회의 실행을 요구하는 구조에서 도출된다. k가 커질 때 소요가 선형을 크게 벗어나면 캐시 경합이나 자원 포화가 발생한 것이므로 확장 가능한 절차로 보기 어렵다. k=1에서 (1+1)=2회, k=10에서 (1+10)=11회이므로 이론상 비율은 5.5배이나, 고정 비용과 측정 오차를 감안하여 8배에서 12배의 범위를 허용한다.

**총 소요 3,600초**는 공공기관의 야간 배치 창을 기준으로 삼았다. 정책 개정과 색인 재구축은 월 단위 이하의 빈도로 발생하며, 업무 시간 외 1시간의 배치 창은 통상적으로 확보 가능하다. 이 시간 안에 전체 검증이 끝나면 운영 일정에 영향을 주지 않는다.

두 기준은 특정 구현의 실측값이 아니라 운영 요건에서 도출하였다.

### H4b 기준값의 근거

암호검증은 배치가 아니라 **모든 질의에서 발생하는 상시 비용**이므로 이용자 체감에 직접 영향을 준다. 따라서 배치 기준과 다른 척도가 필요하다.

**P95 50 ms**는 두 가지로 도출하였다. 첫째, H3-c가 전체 응답의 P95 예산을 3초로 정하고 있으므로, 그 가운데 암호검증에 배정할 수 있는 몫을 약 1.7%로 제한한다. 검증은 검색·순위 계산·응답 구성에 부수하는 절차이므로 전체 예산의 소수 비율을 넘지 않아야 한다. 둘째, 상호작용 응답에서 이용자가 지연을 인지하기 시작하는 구간이 통상 100 ms 부근으로 논의되므로, 그 절반을 상한으로 둔다.

이 값 역시 참조 구현의 실측치가 아니라 응답 예산 배분에서 도출하였다.

## 3. 대상과 규모

| 항목 | 값 |
|---|---|
| 규정 청크 | 실제 기관 코퍼스(규모는 실험 개시 시 기록) |
| 원 질의 | 301개 이상 |
| 대조 질의 | 시점 불변축 1,600개 이상, 시점 가변축(V2) 250개 이상 |
| 직무등급 | 일반·관리·감사 |
| 기준일 | 개정 이전·개정 당일·개정 이후·폐지조항 유효시점·최신의 5개 |
| 역할 사칭 질의 | 100개 |
| 비교 시스템 | S1 BM25 / S2 Dense / S3 Hybrid RRF / S4 사후 필터링 / S5 검색 이전 게이트웨이 |
| 반환 개수 | k = 5 (민감도 분석 k ∈ {1,3,5,10}) |
| 중간 후보 개수 | m = 50 (민감도 분석 m ∈ {20,50,100}) |

시점 불변축 유효 대조쌍이 400개 미만이면 H1a의 Rule of Three 상한 0.0075를 만족할 수 없으므로, 생성 단계에서 이 조건을 먼저 확인한다.

## 4. 측정 지표

| 범주 | 지표 | 정의 |
|---|---|---|
| 보안(최종) | DL_A@k | 시점 불변 대조쌍에서 최종 노출집합에 새로 진입한 비인가 청크 수 |
| 보안(중간) | DL_A^M@m, DL_A^M/m | 중간 후보집합 기준. 정규화값 병기 |
| 보안(시점) | TCV@k | 변경된 시점의 허용집합을 벗어난 노출의 비율 |
| 가용성 | OBR | 격상 이전 허용집합에 속하는 정답 근거 중 격상으로 제외된 비율 |
| 가용성 | Availability@k | 인가된 정답 근거가 상위 k에 제시된 질의의 비율 |
| 품질 | MRR, Hit@k, nDCG@k | 표준 정의 |
| 운영성 | 평균·P95 지연, 배치 소요, 오류율 | 실측 |
| 암호 | 정상 통과율, 공격 탐지율, 검증 지연 | 실측 |

보안 지표는 단독으로 보고하지 않으며 가용성·품질 지표와 같은 표에 병기한다.

## 6. 변경 관리

결과 확인 이후 본 문서의 가설, 임계값, 제외 규칙과 분석 방법을 변경하지 않는다. 불가피한 변경이 발생하는 경우 다음을 모두 공개한다.

1. 변경 사실과 사유
2. 변경 전후의 `config/experiment_config.yaml` SHA-256
3. 변경 시점이 결과 확인 이전인지 이후인지

변경은 새로운 Release(`preregistration-v1.1` 등)로 발행하며, 이전 Release를 삭제하거나 수정하지 않는다.

## 7. 결과 보고 원칙

- 미측정 항목은 0이나 예상치로 대체하지 않고 "미측정"으로 표기한다.
- 판정기준에 미달한 가설은 기준을 수정하지 않고 미달 사실과 원인을 보고한다.
- 통계적 유의성과 실무적 충분성을 구분하여 진술한다. 효과크기가 사전에 정한 실무 임계값에 미달하는 경우, 유의하더라도 개선으로 보고하지 않는다.
