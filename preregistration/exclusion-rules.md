# 전제 위반과 제외 규칙

본 문서는 어떤 실행을 결과 집계에서 제외하는지, 그리고 제외를 어떻게 보고하는지를 실험 착수 이전에 고정한다.

---

## 1. 왜 제외가 필요한가

검색 이전 인가의 보장은 다음 네 전제 위에서만 성립한다.

| 전제 | 요구 조건 |
|---|---|
| **P1** 인증 속성의 신뢰성 | 인가 계산이 질의문의 영향을 받지 않는다 |
| **P2** 정책 캐시 일관성 | 대조쌍의 두 실행이 같은 정책 버전을 사용한다 |
| **P3** 후보집합 연산의 완전성 | 구현된 필터가 허용집합 정의와 외연적으로 일치한다 |
| **P4** 색인 스냅샷 동일성 | 대조쌍의 두 실행이 같은 색인을 사용한다 |

전제가 깨진 상태에서 얻은 관측은 시스템의 성능이 아니라 **검증 조건의 불성립**을 나타낸다. 이를 구분하지 않으면 두 방향의 오류가 발생한다. 전제 위반으로 인한 차등노출을 시스템 결함으로 보고하면 과소평가가 되고, 반대로 위반 사례를 조용히 제외하면 안전성이 과대평가된다.

---

## 2. 제외 규칙

대조쌍의 두 실행에서 다음 중 **하나라도 불일치하면 해당 쌍을 결과 집계에서 제외**한다.

| 번호 | 검사 항목 | 대응 전제 |
|---|---|---|
| E1 | 정책 버전 식별자 | P2 |
| E2 | 정책 캐시 적재 시각(동일 버전 내 재적재 여부) | P2 |
| E3 | 색인 스냅샷 해시 | P4 |
| E4 | 허용집합 A(u,t) 해시 (시점 불변축에 한함) | P1, P2 |

시점 가변축(V2)은 기준시점이 달라지므로 허용집합 해시가 달라지는 것이 정상이며, E4를 적용하지 않는다.

---

## 3. 제외가 아닌 것

다음은 제외 사유가 **아니다**. 축 구분이나 지표 정의에 따른 정상적인 분석 대상 분리이므로, 제외 건수에 포함하지 않는다.

| 상황 | 처리 |
|---|---|
| 시점 가변축(V2)이 차등노출 분석에 포함되지 않음 | 축 구분. 시점 정합성 분석에 사용 |
| OBR 분모가 0인 질의 | 지표 정의상 산출 불가. 집계 모수에서 제외하되 사유 표기 |
| 근사 최근접 탐색으로 인가 청크가 누락됨 | 보안 위반이 아니라 가용성 손실. Availability@k로 관측 |
| 결측 메타데이터 청크 | 실패 폐쇄 규칙에 따라 후보에서 배제. 건수를 별도 보고 |

이 구분을 명시하는 이유는, 분석 대상 수의 차이를 전제 위반으로 오해하는 서술을 방지하기 위해서이다.

---

## 4. 비결정성 처리

각 대조쌍은 3회 반복 실행한다. 3회의 최종 노출집합과 중간 후보집합이 모두 동일하지 않으면 **비결정성 항목**으로 분류한다.

- 집계에는 첫 회차 값을 사용하되, 비결정성 항목임을 표기한다.
- 비결정성 쌍의 수가 전체의 1%를 초과하면 원인을 규명하기 전까지 결과를 확정하지 않는다.

---

## 5. 보고 의무

제외 건수가 0이더라도 다음 표를 반드시 보고한다. 제외 건수를 밝히지 않은 채 제시된 보안 지표는 과대평가될 수 있다.

| 구분 | 사유 | 건수 |
|---|---|---|
| 제외 | 정책 버전 불일치(E1) | |
| 제외 | 정책 캐시 재적재(E2) | |
| 제외 | 색인 해시 불일치(E3) | |
| 제외 | 허용집합 해시 불일치(E4) | |
| 비결정성 | 3회 반복 결과 불일치 | |
| — | 집계에 사용된 최종 쌍 수 | |

추가로 다음을 확인하여 보고한다.

> 제외된 쌍 가운데, 제외되지 않았다면 위반으로 계수되었을 쌍의 수. 이 값이 전체의 5%를 초과하면 제외 규칙의 타당성을 본문에서 재검토한다.

---

## 6. 실험 개시 사전 조건

다음 네 조건이 모두 충족된 뒤에 본 실험을 개시한다. 하나라도 충족되지 않으면 원인을 규명하고 수정한 뒤 재확인한다.

1. 정적 데이터플로우 분석에서 질의 텍스트가 인가 계산으로 유입되는 경로가 0개일 것. **재순위화 모듈과 질의 확장 모듈을 포함한 구성에서 검사한다.**
2. 허용집합 정의의 참조 구현과 실험 시스템의 결과가 (직무등급 × 기준일) 전 조합에서 일치할 것.
3. 실험 기간의 색인 해시가 단일할 것.
4. 역할 사칭 질의 100개에서 허용집합 해시 변화가 0건일 것.

사전 조건의 충족 여부와 확인 시각을 기록하여 결과와 함께 공개한다.
